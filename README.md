# Basic-Notepad
This is a your Notepad! Made with Love and Java

## Instructions
For Windows:
1. Download Java 17 (LTS): https://adoptium.net/temurin/releases/?version=17
   (Windows x64 .msi → Next → Next → Finish)
2. Compile with build.bat
3. Double click on run.bat
4. Enjoy

For Linux:
1. Download Java 17 (LTS): https://adoptium.net/temurin/releases/?version=17
2. Compile with build.sh
3. Double click on Notepad.jar (open with JDK17+)
4. Enjoy
